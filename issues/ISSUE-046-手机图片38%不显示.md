# 38% 手机的商品图片永远不显示，且完全静默

> 创建时间: 2026-09-12 | 状态: 🔴未解决

## 问题描述

推荐结果卡片中，大量手机**没有图片**（显示默认图标），且**没有任何报错**——无破图图标、无 console 错误、网络面板里**连请求都不发出**。

实测：一次返回 3 张卡片时，DOM 中只有 **1 个 `<img>`**。其中 `X200 Pro` 有图，`X200` 与 `小米14` 无图。

对全库 352 条统计 `imageUrl` 格式：

| 格式 | 条数 | 占比 |
|---|---|---|
| `http(s)` 外链（中关村在线图床） | 169 | 48% |
| **`images\...` 反斜杠（Windows 路径）** | **132** | **38%** |
| `/images/...` 正斜杠 | 43 | 12% |
| 空 | 8 | 2% |

即 **132 条（38%）的手机图片永远无法显示**。

## 出现原因

`frontend/src/components/PhoneCard.tsx:91-99` 的 URL 拼接逻辑，两处缺陷叠加：

```js
const API_BASE = import.meta.env.VITE_API_BASE || 'http://localhost:8002';  // 结尾无斜杠
...
const encoded = url.includes('%') ? url : encodeURI(url).replace(/\+/g, '%2B');
return `${API_BASE}${encoded}`;
```

对反斜杠路径 `images\vivo X200(16GB1TB)_1.jpg`：

1. `API_BASE` 结尾无 `/`，且 `encodeURI` **不会**把 `\` 规范化成 `/`（而是编码为 `%5C`）
2. 拼出 `http://localhost:8002images%5Cvivo%20X200(16GB1TB)_1.jpg`

结果**主机名被吃成 `localhost:8002images`**。在浏览器内按组件相同逻辑复刻，实测：

```
Failed to parse URL from http://localhost:8002images%5Cvivo%20X200(16GB1TB)_1.jpg
```

浏览器拒绝解析 → 请求根本不发出 → `onError` 触发 → `imageError=true` → 静默换成默认图标。这解释了为什么网络面板里看不到失败请求。

（正斜杠的 43 条拼接正确，`http://localhost:8002/images/...` 能正常 200。）

## 解决方案

两个方向都建议做：

1. **前端容错**（治标，立即见效）：`getFullImageUrl` 中把 `\` 统一替换为 `/`，并确保 `API_BASE` 与路径之间有且只有一个 `/`
2. **数据归一**（治本）：清洗数据库中 132 条反斜杠格式的 `imageUrl`，统一为 `/images/...` 或完整 http 外链

## 验证方式

随机抽一条反斜杠 imageUrl 的手机（如 id=1482 OPPO A32、id=1321 华为畅享 80、id=1537 真我15T）渲染卡片，应能正常发出图片请求并显示图片；DOM 中 `<img>` 数量应与卡片数量一致。
