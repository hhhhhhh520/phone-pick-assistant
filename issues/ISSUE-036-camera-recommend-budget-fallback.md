# 拍照推荐场景失效：5000预算推799元入门机
> 创建时间: 2026-07-02 | 状态: 🟢已解决

## 问题描述

用户输入"推荐一款拍照好的手机，预算5000左右"，系统推荐出 **799 元努比亚小牛** 和 **1049 元华为畅享 80**，与用户预算差距 5 倍以上。LLM 自己在回复中承认"列表中的手机价格均在1000元左右，与您的预算差距较大"。

## 出现原因

根因链（日志 + 数据库查询验证）：

1. 意图识别正确：`budget_min=4500, budget_max=5500, camera_need=HIGH`（后端日志确认）
2. `retrieval.py` 拍照场景的 OR 过滤条件只匹配 4 个关键词：`徕卡 / 哈苏 / 蔡司 / 摄影爱好者`（`_build_feature_filters` 第 227-237 行）
3. 数据库 4500-5500 档有 **38 款旗舰**（小米14 Pro/Ultra、Mate 70、vivo X200 Pro mini、Find X9 Pro 等），但它们的 `features` 字段用的是"超大杯影像""潜望长焦"等表述，`suitable_for` 为空 `[]` → **0 款命中拍照关键词**
4. 过滤结果为空 → `chat.py:172-174` 回退到 `retrieval.get_all_phones(5)`
5. **`get_all_phones` 回退时不保留预算过滤**，只按"有图片优先"排序，返回全库最便宜的 5 款入门机
6. LLM 硬着头皮从入门机里挑"拍照相对好的"

## 解决方案

需要两层修复（本次仅记录，不改代码）：

**方案A（关键词扩展，治标）**：`_build_feature_filters` 拍照分支增加"影像""潜望长焦""大底""人像"等关键词，并放宽到 `camera_main` 像素阈值（如 ≥5000万）。

**方案B（回退保留预算，治本）**：`get_all_phones` 或回退逻辑必须保留 `intent_result` 的预算/品牌过滤，否则任何场景过滤为空都会退化成"推最便宜的"。

建议两者都做：B 是安全网，A 提高命中率。游戏/续航场景大概率有同样的回退失效问题，需一并验证。
