# QA测试计划 - 手机选购助手

> 创建时间: 2026-05-05 | 项目: phone-pick-assistant

## 测试范围

### 核心功能测试
1. **多轮对话引导** - 追问流程、快捷回复、状态累积
2. **手机推荐** - 意图识别、检索准确性、推荐结果展示
3. **手机对比** - 型号匹配、对比表格展示
4. **搜索历史** - 历史记录存储、展示、清除

### UI/UX测试
1. **聊天界面** - 消息展示、输入框、发送按钮
2. **手机卡片** - 图片加载、参数展示、点击交互
3. **快捷回复** - 按钮展示、点击响应
4. **错误处理** - Error Boundary、网络错误、超时处理

### 边界情况测试
1. **空输入** - 空消息发送
2. **超长输入** - 超过500字符的消息
3. **特殊字符** - Prompt注入尝试、控制字符
4. **并发请求** - 多个请求同时发送
5. **网络中断** - 请求取消、连接断开

### 性能测试
1. **响应时间** - 首屏加载、消息响应
2. **内存使用** - 长时间运行、大量消息
3. **并发能力** - 多用户同时访问

## 测试场景

### 场景1: 新用户首次访问
- 打开首页
- 查看界面布局
- 发送第一条消息"推荐一个手机"
- 观察追问流程

### 场景2: 明确需求用户
- 发送"推荐3000元左右的游戏手机"
- 观察推荐结果
- 点击手机卡片查看详情

### 场景3: 多轮对话用户
- 第一轮: "推荐一个手机"
- 第二轮: 选择快捷回复"2000-3000元"
- 第三轮: 选择"王者/吃鸡"
- 第四轮: 选择"日常记录"
- 观察最终推荐

### 场景4: 对比功能用户
- 发送"对比小米14和华为P60"
- 观察对比表格
- 检查型号匹配准确性

### 场景5: 追问用户
- 第一轮: "推荐一个手机"
- 第二轮: "有没有便宜点的"
- 观察上下文理解

### 场景6: 异常输入用户
- 发送空消息
- 发送超长消息
- 发送特殊字符
- 观察错误处理

## 测试Agent分配

| Agent | 测试场景 | 重点 |
|-------|----------|------|
| API Tester | 后端API测试 | 健康检查、聊天API、手机API |
| Frontend Developer | 前端UI测试 | 聊天界面、手机卡片、快捷回复 |
| UX Researcher | 用户体验测试 | 多轮对话流程、交互流畅度 |
| Performance Benchmarker | 性能测试 | 响应时间、并发能力 |
| Security Engineer | 安全测试 | Prompt注入、输入验证 |

## 预期产出

1. QA测试报告 - 发现的问题、严重程度、修复建议
2. 性能基准 - 响应时间、并发能力数据
3. 安全评估 - 漏洞发现、风险评估
4. UX评估 - 用户流程问题、改进建议
