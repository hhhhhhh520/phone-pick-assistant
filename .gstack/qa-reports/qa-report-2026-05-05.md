## 发现的问题

### 高优先级 (P1)

#### ISSUE-001: 对比功能错误触发追问流程

**严重程度**: 高 | **影响范围**: 核心功能

**问题描述**:
用户发送"对比小米14和华为P60"时，系统识别意图为`compare`，但错误地触发了追问流程而不是直接展示对比结果。

**根本原因**:
`chat.py` 第100-102行逻辑问题:
```python
need_clarification = (
    not user_profile.is_complete() and not _is_explicit_request(intent_result)
)
```
此逻辑对所有非明确请求检查需求完整性，但对比模式不应受此限制。

**修复建议**:
```python
need_clarification = (
    intent_result.intent != IntentType.COMPARE and
    not user_profile.is_complete() and 
    not _is_explicit_request(intent_result)
)
```

**文件**: `backend/api/routes/chat.py`

---

### 中优先级 (P2)

#### ISSUE-002: CORS配置过于宽松

**严重程度**: 中 | **影响范围**: 安全

**问题描述**:
开发模式下`allow_origins=["*"]`与`allow_credentials=True`组合存在安全隐患，恶意Origin被接受。

**修复建议**:
```python
if settings.app_env == "development":
    allow_origins = ["http://localhost:5173", "http://localhost:5174", "http://127.0.0.1:5173"]
```

**文件**: `backend/main.py`

---

#### ISSUE-003: Rate Limiting未生效

**严重程度**: 中 | **影响范围**: 安全

**问题描述**:
slowapi Limiter已初始化但路由未添加限流装饰器，`/api/chat`接口无任何限流保护。

**修复建议**:
```python
@router.post("")
@limiter.limit("20/minute")
async def chat(...):
```

**文件**: `backend/api/routes/chat.py`

---

#### ISSUE-004: 品牌过滤中文参数问题

**严重程度**: 中 | **影响范围**: 用户体验

**问题描述**:
URL中文参数(如`?brand=小米`)返回400错误，可能是URL编码处理问题。

**影响范围**: 所有包含中文的查询参数

**文件**: `backend/api/routes/phones.py`

---

### 低优先级 (P3)

#### ISSUE-005: 前端API默认端口不一致

**严重程度**: 低 | **影响范围**: 开发体验

**问题描述**:
`api.ts`默认端口8000，`PhoneCard.tsx`默认端口8002，实际后端端口8002。

**修复建议**:
统一默认端口为8002。

**文件**: `frontend/src/services/api.ts`
